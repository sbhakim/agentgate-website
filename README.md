# AgentGate Playground website

Static project showcase for GitHub Pages. This does not host the interactive Python application.

App source: https://github.com/sbhakim/agentgate_playground

## Publish

In this repository's Settings → Pages, choose **Deploy from a branch**, **main**, and **/(root)**, then Save.

The initial address is https://sbhakim.github.io/agentgate-website/.

For the custom domain, verify ownership in GitHub account Settings → Pages first. Then add `agentgateplayground.design` under the repository's Pages custom-domain setting before changing Porkbun DNS. Enable HTTPS when GitHub offers it.

The app logo and screenshots are reused from the project. AI tools assisted the site implementation. No API keys, backend, analytics, or signup forms are included.
